# Ảnh giao diện onboarding V13

- [Trang chính kỹ thuật viên bản V13](technician-home-v13.png) minh họa kho
  ESP32, biểu mẫu tạo bộ cửa và danh sách bộ cửa đã tạo.
- [Cài Wi-Fi ESP32](node-wifi-setup-v13.png) minh họa tên mạng, mã thiết lập và
  thao tác chọn Wi-Fi nhà.
- [Kho ESP32 trên web](technician-web-inventory.png) và
  [xem cấu hình nạp](technician-web-firmware-config.png) minh họa giao diện
  kỹ thuật viên trên laptop.

Ảnh render từ các widget TechnicianScreen và NodeWifiScreen
với theme/font/icon Flutter và dữ liệu tổng hợp. Viewport 430 × 1180 logical
pixels, PNG ở pixel ratio 2. Mã Node/setup và bộ cửa trong ảnh là ví dụ,
không có credential thật. Kết nối SoftAP, Wi-Fi nhà và phần cứng cần
kiểm thử trên thiết bị thật.
