# Kiến trúc tương lai

Khu vực lưu đề xuất kiến trúc, refactor và quyết định kỹ thuật chưa được áp dụng vào hệ thống hiện tại.

Tài liệu tại đây phải ghi rõ trạng thái `Đề xuất`, tiêu chí đánh giá và điều kiện áp dụng. Kiến trúc đang hoạt động được lưu trong [tham khảo kỹ thuật](../03-technical-reference/README.md).
